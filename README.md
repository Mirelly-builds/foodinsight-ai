# FoodInsight AI

### Inteligência de Avaliações e Apoio à Decisão para Restaurantes

O **FoodInsight AI** é um projeto-piloto que utiliza IA generativa para transformar avaliações de clientes em informações estruturadas, identificando padrões de satisfação, problemas recorrentes e oportunidades de melhoria.

**Cliente fictício:** Momoshi — restaurante japonês.

## Objetivo

Demonstrar como a inteligência artificial pode apoiar a análise de feedbacks de clientes e contribuir para decisões mais estratégicas na gestão de restaurantes.

## Como funciona

1. Organização de avaliações fictícias de clientes.
2. Análise dos comentários com IA generativa.
3. Classificação por sentimento e categorias.
4. Geração de justificativas e recomendações de melhoria.
5. Organização dos resultados em um dashboard interativo.

## Tecnologias e ferramentas

- Python e Google Colab
- IA generativa via OpenRouter
- Excel
- Looker Studio

## Resultados do projeto

Foram analisadas 50 avaliações fictícias, com os seguintes resultados:

- **50** avaliações processadas.
- **3,14/5** de média das avaliações.
- **38%** de sentimentos negativos.
- **34%** de sentimentos mistos.
- **28%** de sentimentos positivos.
- **8** recomendações passaram por revisão humana.

As avaliações podem receber mais de uma categoria, permitindo identificar diferentes aspectos de uma mesma experiência.

## Limitações

Este projeto é um protótipo acadêmico e demonstrativo, desenvolvido com dados fictícios. Não possui integração com sistemas reais de restaurantes nem atualização automática de avaliações. As recomendações geradas pela IA exigem validação humana.
